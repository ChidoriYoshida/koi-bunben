全体の流れ（全部門 共通・方法A）

① 担当者（スマホ・iPad）
各舎のリンクで入力 → 「集計」画面で「バックアップ保存」→ .json ができる
→
② メール送付
.json を部門の事務所へメール添付で送信
→
③ 事務所PC
同じリンクを開く →「バックアップ読込」→ 印刷
※ 担当者側で「印刷／PDF」からPDF化してメール送付する方法Bも可（事務所はPDFをそのまま印刷）。

事務所での受領・印刷

  1. メールの .json を端末に保存。
  2. 該当する入力リンクを開く。
  3. 「集計」画面 →「バックアップ読込」→ .json を選ぶ。
  4. データが入る →「印刷」で出力。
  5. 分担時は「部屋を合算して読込」（分娩・子豚）／「合算して読込」（母豚舎）で各自の.jsonを1つずつ取り込む（入力済みだけ合算・同じ箇所は後勝ち）。

システムの更新（GitHub）

  1. リポジトリ koi-bunben を開く。
  2. 「Add file → Upload files」で新ファイルをドラッグ。
  3. 同じファイル名で上書きして「Commit changes」。
  4. 数分で全員のリンクが最新化（担当者の再アップロード不要）。
ファイル名：index.html / kobuta.html / koi-botonsya.html / koi-dai2-nikuton.html / koi-dai3-nikuton.html と各マニュアル。

トラブル対応

  • 画面が真っ白：数分待って再読み込み（公開直後は反映待ち）。
  • 前回データが出ない：データは端末ごと保存のため。方法Aで.jsonを受け渡す。
  • データが消えた：保存済みの.jsonから「バックアップ読込」で復元。
  • 「クリア／消去」は全消去。次回の棚卸開始時のみ使用。
